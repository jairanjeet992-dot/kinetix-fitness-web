# Coach Kai Motion Production Kit

Phase 9.1 pilot specification for fictional Kinetix coach `coach-kai`.

Pilot exercises:
air-squat, push-up, pull-up, romanian-deadlift, walking-lunge, bicep-curl, forearm-plank, jumping-jack.

This directory contains production specifications, NOT final MP4/WebP assets.

Final binaries must be visually reviewed and tested in Workout Player, Exercise Detail and Exercise Library before the remaining 39 exercises are produced.

Production paths:
assets/media/coach-kai/<exercise>.mp4
assets/media/coach-kai/<exercise>-poster.webp
assets/media/coach-kai/<exercise>-thumb.webp
