# Romanian Deadlift
Pattern: hinge | Tempo: 3-1-1-0
Start: Tall stance, load close to thighs, soft knees, stacked ribs/pelvis.
Movement: Hinge hips backward; load stays close; spine neutral.
End: Controlled hamstring tension; drive hips forward to standing.
Avoid: rounded back, excessive knee bend, load drifting away.
