# Kinetix Exercise Visual System — Prototype Pack

## Status
Prototype/reference assets only. These visuals are **not** the final production exercise media set.

## Direction
Kinetix uses the selected **Clean Fitness 3D** visual language:
- stylized 3D fitness character
- dark graphite studio
- Ember Red/orange accents
- clear target-muscle visualization
- mobile-first presentation
- consistent exercise-card composition

## Prototype set
Eight representative exercises are included:
- Air Squat
- Push-Up
- Pull-Up
- Barbell Bench Press
- Bicep Curl
- Shoulder Press
- Walking Lunge
- Forearm Plank

These are intended to validate dashboard/library visual hierarchy before scaling the system to the full exercise catalog.

## Important
The images in this folder are generated visual prototypes. Do not treat them as final licensed production assets or as proof of exercise-video completion. Final production assets should pass visual QA, biomechanics review, provenance/licensing review, and responsive/mobile QA before being promoted into `assets/media/` runtime paths.
